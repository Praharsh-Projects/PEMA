# SYNTHETIC_OFFLINE_NOT_CHESSCON — Claim Boundary

This directory contains an **offline, stochastic, uncalibrated discrete-event simulation** for development and methods illustration. It models one STS crane, five internal transfer vehicles, one yard service point, and one pre-stage position.

It does not contain a terminal deployment, a field-calibrated model, a CHESSCON project, or a native simulation-platform treatment run. No CHESSCON diagnostic or staging-clone material is included or used in any R0/R1 calculation in this package.

Use only these descriptions in the manuscript and reviewer response:

- “offline synthetic discrete-event simulation”
- “synthetic development evidence”
- “paired simulated scenario summaries”
- “future native CHESSCON validation remains required”

Do not use the generated numbers as terminal productivity, field, platform-treatment, or operational-performance outcomes. The controller is advisory in concept: it selects readiness candidates and fallbacks but does not override an operator.

All generated tables, data files, figures, and manifests carry the label `SYNTHETIC_OFFLINE_NOT_CHESSCON`.
